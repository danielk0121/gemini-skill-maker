# Gemini Skill Maker - Session Handover Skill

## 개요
이 프로젝트는 Gemini CLI를 위한 전용 스킬인 `session-handover`를 생성하고 관리하는 프로젝트입니다.
`session-handover` 스킬은 현재 세션의 요약을 자동화하고, "최종 구조"를 메모리에 저장하며, `/clear`를 통해 세션을 초기화하도록 안내하는 기능을 제공합니다.

## 주요 기능
- **세션 요약**: 현재 작업의 목표, 진행 상황, 주요 결정 사항, 다음 단계 등을 요약합니다.
- **메모리 저장**: 요약된 내용을 `save_memory` 도구를 사용하여 `project` 범위의 "최종 구조"로 저장합니다.
- **세션 초기화 안내**: 작업 내용이 보존되었음을 알리고 세션 초기화를 제안합니다.

## 프로젝트 구조
- `session-handover/SKILL.md`: 스킬의 상세 정의 및 워크플로우를 담고 있습니다.
- `session-handover.skill`: 배포 및 설치가 가능한 스킬 패키지 파일입니다.
- `report_session_handover_스킬생성.md`: 스킬 생성 과정에 대한 작업 보고서입니다.
- `build.sh`: 스킬 패키징을 위한 빌드 스크립트입니다.
- `GEMINI.md`: 프로젝트의 언어 규칙 및 관련 메모를 포함합니다.

## 사용 방법
### 1. 스킬 설치
워크스페이스 범위로 스킬을 설치합니다.
```bash
gemini skills install session-handover.skill --scope workspace
```

### 2. 스킬 로드
세션 내에서 설치된 스킬을 로드합니다.
```bash
/skills reload
```

### 3. 스킬 실행
작업이 완료되었을 때 "파이널퓨전"이라고 입력하거나 작업 종료를 알리면 스킬이 활성화됩니다.
- "파이널퓨전"
- "이 기능 작업 끝났어."
- "오늘 작업은 여기까지 할게."

## 개발 규칙
- **문서**: 한국어를 가급적 사용하며, 파일명 및 내용 모두 한국어 관례를 따릅니다.
- **코드**: 소스 코드 및 관련 파일명은 영어 관례를 따르며, 주석은 한국어로 작성합니다.
- **커밋 메시지**: 한국어로 작성합니다.

## `session-handover.skill` 파일 패키징 안내
`session-handover.skill` 파일은 컴파일 과정을 거쳐 만들어지는 실행 파일이 아니라, 스킬 폴더 내부에 있는 `SKILL.md`와 관련 파일들을 하나로 묶어 확장자만 바꾼 **ZIP 압축 파일**입니다. 압축 파일 구조를 가지기 때문에 IDE나 에디터에서는 텍스트로 열 수 없는 바이너리 형식으로 인식하는 것입니다.

따라서 별도의 빌드 도구를 설치할 필요 없이 터미널에서 기본 `zip` 명령어를 사용해 간단하게 패키징할 수 있습니다. 

현재 작업 중인 `gemini-skill-maker` 디렉토리 위치에서 아래 명령어를 실행하시면 됩니다.

```bash
zip -r session-handover.skill session-handover
```

명령어를 실행하면 `session-handover` 폴더 내부의 모든 내용이 하나의 `.skill` 파일로 묶이며, 이후 Gemini CLI 환경에서 해당 파일을 커스텀 스킬로 정상적으로 불러와 사용할 수 있습니다.
